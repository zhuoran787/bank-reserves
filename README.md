# 银行家底与估值对照

永久网址：https://zhuoran787.github.io/bank-reserves/

22家A股银行；按用户要求排除3家香港银行。家底来自银行先爽2026年中报数据库，估值来自用户提供的长江证券2026-10-12图片、A股2026E全年预测。

默认家底三维度等权，可在浏览器调节；估值PB与股息率百分位各50%。另列研究范围内11家H股比较：家底分数沿用22家计算，在这11家内部重新编号，再与11家H股定价排名比较；同时展示原22家排名。便宜程度排名以低PB、高股息率为优；定价排名以高PB、低股息率为前。偏差=定价排名-家底排名。并列使用同名次并跳号。

来源文件、文件更新日、财报期、TTM/期末/预测口径均在网页标注；点击银行可查看单元格。自由现金流1为基于TTM等输入的模型比率，非财报现金金额。

这是人工发起的快照更新，未配置定时自动刷新。发布前必须核对全部来源值、权重联动、同范围排名并独立审查。数据缺失或口径变动应明确报出，不用旧值假装更新。

CET1安全垫先乘RWA换算金额，再除统一归母净资产/TTM利润。资本组权重由config中的指标配置决定，保留安全垫与FCF1的原相对权重。绝对总家底按用户最终指定公式：折扣后AC浮盈+超额拨备+CET1安全垫金额；AC由AC&OCI浮盈减OCI得到，再按absolute_model.ac_discount_factor计入，OCI不再单列。采用拨备库统一归母分母，机械加总不随排名权重变动，A/H分别与原始估值并列。该研究总量未进一步调整税务及资本拨备其他重叠，不是可分配现金。

四张比较表直接同时展示。绝对值表默认按家底调整后PB=原PB/(1+总家底/归母净资产)从低到高排名，A/H分别计算。原PB为2026E、家底比例为2026H1，明确标为混合期近似。另列PB下降倍数=原PB-调整PB，可独立排序。小数两位、按完整精度排名；数字色阶按原始差距线性渐变，筛选不变色。

顶部突出展示两种方法综合排名，权重及边界家数由combined.mjs的combination定义，A/H分别计算、边界并列一并展开；保留两法分项名次。nii-growth.json提供最近半年度净利息收入累计同比增速，仅供展示，不参与排名。来源单元格、报告期和文件下载链接可在页面核查。
