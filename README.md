# 银行家底与估值对照

22家A股银行；按用户要求排除3家香港银行。家底为2026Q3/H1混合期：拨备与NII采用用户新下载的三季报库；浮盈两项及自由现金流1完整保留H1；资本安全垫按Q3核充率和RWA同比增速桥接推算。估值来自用户提供的长江证券2026-11-20图片、A/H股2026E全年预测。

新增“累计已核销不良／总资产”：取用户财报修正版工作簿D列，实际为2021H2–2026H1累计核销及转出额÷2022年末与2026H1末总资产均值。沪农商行缺2021H2，跳过缺数并标*。季度资料不足时保留最近可还原半年度；以后累计起点不动，延伸至最新可还原截止期，分母基期仍固定2022年末。拨备组四项等权，均按越高得分越高。核销金额不加入调整PB。

默认家底三维度权重读取配置（本次浮盈20%、拨备50%、资本30%），可在浏览器调节；估值PB与股息率百分位各50%。另列研究范围内11家H股比较：家底分数沿用22家计算，在这11家内部重新编号，再与11家H股定价排名比较；同时展示原22家排名。便宜程度排名以低PB、高股息率为优；定价排名以高PB、低股息率为前。偏差=定价排名-家底排名。并列使用同名次并跳号。

中国银行第一法采用用户批准的“境内可比性调整”，参数与指标映射以first-method.mjs的firstMethodPolicy为唯一配置：利润、权益和平均资产分母分别按对应factor缩小，拨贷比按loan_provision_add_pp加百分点；各分子及自由现金流1保留集团原值。raw_value保存集团原比率，value用于第一法评分，每次从原值重算，避免重复叠加；详情与CSV可还原。它是研究假设，不是实际境内分部报表。第二法、绝对家底表及原始财务资料全部保持集团口径；A/H共用主体修正，全部银行重算第一法百分位和综合榜。政策文件指纹同时记录在config/data，网页核对实际文件，不匹配拒绝旧数据；生成顺序为build_first_method.mjs，再重建ROE产物输入指纹，发布前须通过verify_first_method.mjs和独立复算。

来源文件、文件更新日、财报期、TTM/期末/预测口径均在网页标注；点击银行可查看单元格。自由现金流1为基于TTM等输入的模型比率，非财报现金金额。

这是人工发起的快照更新，未配置定时自动刷新。发布前必须核对全部来源值、权重联动、同范围排名并独立审查。数据缺失或口径变动应明确报出，不用旧值假装更新。

页面初始家底权重读取data.groups[].weight，与config.groups[].weight同步，由生成器的groups定义。网页初始化与计算引擎共用该默认值。“恢复等权”按钮将三维度设为等权，重新载入页面则使用配置中的默认权重。

CET1安全垫先乘RWA换算金额，再除统一归母净资产/TTM利润。资本组权重由config中的指标配置决定，保留安全垫与FCF1的原相对权重。用于PB调整的总家底按用户最终指定公式：折扣后AC浮盈+超额拨备。CET1安全垫仅供对照及资本宽裕度评分，不计入该合计，也不从原归母净资产扣除。合计项目由build_data.py的absolute_model.total_components唯一定义，历史提取器与本轮快照重算共用absolute_model.py；AC由AC&OCI浮盈减OCI得到，再按absolute_model.ac_discount_factor计入，OCI不再单列。采用拨备库统一归母分母，机械加总不随排名权重变动，A/H分别与原始估值并列。该研究总量仍未进一步调整税务及超额拨备与账面净资产的其他重叠，不是可分配现金。

四张比较表直接同时展示。A/H绝对值表首个数字列为“调整后ROE vs PB偏离度 / 排名”，位于原“家底调整后PB / 排名”左侧，两列均用黑框突出；默认按偏离度由小到大排列。原PB为2026E，用于PB调整的家底包含H1浮盈与Q3超额拨备，分母采用Q3归母净资产。旧调整后PB及其自身名次、PB下降倍数仍可独立排序。小数两位、按完整精度排名；偏离保留正负号，数值越低越绿，筛选不改变样本或色阶。

调整后ROE＝截至2026-09-30的TTM归母净利润÷（Q3归母净资产＋总家底），浮盈、拨备只加到净资产，不加入利润。总家底仅含折扣后AC和超额拨备，负值保留；不加CET1或OCI，不使用源表ROE或前三季度利润乘4/3。A股22家、H股11家单独做等权、含截距OLS：纵轴为ROE的百分数值，横轴为调整后PB；先拟合y=a×x+b，再沿同一条线反算趋势线PB=(y-b)/a，估值偏离=x-趋势线PB。按有符号偏离从小到大排名，不取绝对值，也不反过来回归PB对ROE。

顶部突出展示两种方法综合排名：排名偏差法名次占66%，ROE—PB偏离度名次占34%，加权名次越小越靠前。权重及边界家数由combined.mjs的combination定义；A股后段采用aTailCount，其余榜单采用edgeCount，标题与筛选共用该配置；A/H分别计算、边界并列展开，保留两法分项名次。家底滑块只改变第一法及综合榜；第二法拟合、名次不随滑块或搜索变化。nii-growth.json提供2026年前三季度净利息收入累计同比增速，仅供展示，不参与排名。

ROE—PB图表在网页中提供A/H两份静态PNG、SVG与完整排名CSV，包含所有银行名称、拟合公式和R²。计算由roe.mjs共用；build_roe_artifacts.mjs导出数值与CSV，plot_roe_artifacts.py从同一数值快照绘图。roe-valuation.json绑定输入与计算文件指纹、六个下载文件指纹；网页发现输入不一致即拒绝旧图表，下载链接附文件指纹防缓存混用。每次估值、利润、净资产、家底或计算口径变化必须重新拟合并重绘，通过verify_roe_model.py再发布，不能沿用本轮系数。完整生成及核验命令见本地SOP。

这是混合报告期研究近似。趋势线描述样本关系，偏离是PB倍数差，不是低估百分比、合理价格或预期股价涨幅。两法共享输入，不是两份独立证据；拟合斜率为零或过小时停止反算，缺数、非正调整后净资产亦停止比较，不跳过银行凑结果。
